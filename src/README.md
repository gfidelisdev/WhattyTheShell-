# src

## Overview
Core application crate entry point and UI/session layer for `WhattyTheShell!`, integrating GTK4 windowing, custom `TerminalView` widget lifecycle, pseudo-terminal (`Pty`) process management, recursive `gtk4::Paned` split views, saved SSH sessions with remote `tmux`/`screen` bootstrap and Secret Service keyring + askpass broker, TOML configuration persistence, system font discovery, and VS Code Marketplace theme integration.

## Interface
- `[main.rs:main]`: Binary entry point handling pre-GTK `--ssh-askpass` child invocations (`[ssh.rs:run_askpass_client_and_exit]`), starting the singleton `[ssh.rs:AskpassBroker]`, and initializing `gtk4::Application` (`io.github.whattytheshell`), `wgpu` Vulkan `Device`/`Queue`, `ApplicationWindow` (`1024x768`), HeaderBar Saved SSH Sessions menu, `gio::SimpleAction`s (`win.new-tab`, `win.split-right`, `win.split-down`, `win.unsplit`, `win.close-pane`, `win.move-tab-left`, `win.move-tab-right`, `win.prev-tab`, `win.next-tab`, `win.preferences`, `win.launch-ssh-profile`, `win.toggle-tabs`, `app.quit`), and local session tab restoration.
- `[main.rs:is_pointer_in_tab_bar]`, `[main.rs:handle_smooth_tab_scroll]`, `[main.rs:truncate_middle]`, `[main.rs:format_dir_path]`: Public tab-bar hit-testing, smooth scroll tab switching, and path/title formatting utilities.
- `[config.rs:MultiplexerKind]`, `[config.rs:SshAuthKind]`, `[config.rs:SshProfile]`, `[config.rs:default_multiplexer_order]`, `[config.rs:TabOrientation]`, `[config.rs:GpuBackend]`, `[config.rs:SavedTab]`, `[config.rs:Config]`, `[config.rs:ConfigManager]`: Configuration schema and atomic `0o600` persistence manager (`load_or_default`, `save`, `save_user_config`, SSH profile CRUD `ssh_profiles`, `get_ssh_profile`, `upsert_ssh_profile`, `remove_ssh_profile`, corrupt config backup protection, and getters/setters for window, theme, font, shell, and tab state).
- `[fonts.rs:FontFamilyInfo]`, `[fonts.rs:shared_font_db]`, `[fonts.rs:get_cached_face_data]`, `[fonts.rs:query_system_fonts]`, `[fonts.rs:fuzzy_match]`, `[fonts.rs:filter_fonts]`: Lazily initialized `fontdb::Database`, shared `Arc<[u8]>` font face cache, and fuzzy font search ranking.
- `[gpu_renderer.rs:GPURenderer]`: Backend selector (`GPURenderer::new`, `GPURenderer::backend_name`) resolving user preference or compile-time features (`vulkan`, `opengl`, `Software`).
- `[pty.rs:ShellOption]`, `[pty.rs:discover_installed_shells]`, `[pty.rs:Pty]`: Shell discovery (`/etc/shells`, `COMMON_SHELLS`, `$SHELL`) and pseudo-terminal process manager (`spawn`, `spawn_with_env`, `spawn_with_shell`, `spawn_shell`, `current_working_dir`, `try_wait_exit_code`, `raw_fd`, `try_read`, `reader`, `writer`, `write_all`, `resize`, `child_pid`, `terminate`). Implements `Drop`.
- `[settings_dialog.rs:open_settings_dialog]`: Modal GTK4 preferences, VS Code theme browser, and `SSH Sessions` profile/keyring manager (`820x600`).
- `[split.rs:MAX_PANES_PER_TAB]`, `[split.rs:find_terminals]`, `[split.rs:find_focused_terminal]`, `[split.rs:find_focused_terminal_with_active]`, `[split.rs:find_page_root]`, `[split.rs:find_page_by_tab_label]`, `[split.rs:split_terminal_with_widget]`, `[split.rs:split_terminal]`, `[split.rs:close_pane]`, `[split.rs:unsplit_terminal]`, `[split.rs:unsplit_active_tab]`, `[split.rs:cleanup_tab_label]`, `[split.rs:merge_tabs]`: Multi-pane split tree operations over `gtk4::Notebook` and nested `gtk4::Paned` containers.
- `[ssh.rs:SecretServiceClient]`, `[ssh.rs:AskpassBroker]`, `[ssh.rs:AskpassAttempt]`, `[ssh.rs:run_askpass_client_and_exit]`, `[ssh.rs:build_remote_bootstrap_script]`, `[ssh.rs:build_ssh_invocation]`: FreeDesktop `org.freedesktop.secrets` keyring integration, per-attempt UNIX-socket `SSH_ASKPASS` broker with `SO_PEERCRED` peer verification and GTK4 password/confirmation dialogs, POSIX `sh -c` `tmux`/`screen` remote bootstrap generator, and `ssh` command/env builder.
- `[tab_group.rs:TabGroup]`: Wrapper around `gtk4::Notebook` (`TabGroup::new`, `TabGroup::add_tab`, `TabGroup::widget`, `TabGroup::set_orientation`).
- `[theme_manager.rs:ThemeManager]`: GTK `CssProvider` theme applier (`ThemeManager::new`, `ThemeManager::apply_to_window`, `ThemeManager::apply_palette`, `ThemeManager::set_theme`).
- `[theme_marketplace.rs:Extension]`, `[theme_marketplace.rs:Publisher]`, `[theme_marketplace.rs:ExtensionVersion]`, `[theme_marketplace.rs:DownloadProgress]`, `[theme_marketplace.rs:search_themes]`, `[theme_marketplace.rs:extract_key_swatches]`, `[theme_marketplace.rs:popular_presets]`, `[theme_marketplace.rs:find_builtin_theme]`, `[theme_marketplace.rs:get_cached_theme]`, `[theme_marketplace.rs:download_and_extract_theme_with_progress]`, `[theme_marketplace.rs:download_and_extract_theme]`: Built-in theme presets and VS Code Marketplace search/VSIX extraction/disk caching.
- `[widget.rs:SessionOrigin]`, `[widget.rs:TerminalView]`: Custom `gtk4::Widget` subclass (`WhattyTerminalView`, signal `"child-exited"`, `term` action group with `"copy"` and `"paste"`) managing double-buffered `DmabufFrame` rendering, GLib FD polling (`unix_fd_add_local`), saved SSH session hold-open EOF banners, keyboard/IME input, mouse drag selection with autoscroll, and Ctrl+click URL/path opening. Methods: `terminate`, `sync_scale_and_dimensions`, `with_working_dir`, `with_shell_and_working_dir`, `with_ssh_profile`, `new`, `set_palette`, `set_font`, `set_font_size`, `set_font_family`, `current_working_dir`, `session_origin`, `is_awaiting_error_dismiss`, `auto_tab_title`, `custom_title`, `set_custom_title`, `pixel_to_cell`, `pixel_to_buffer_cell`, `copy_selection`, `paste_clipboard`, `paste_primary`, `show_context_menu`, `set_saturation_boost`, `open_url`.
- **Subdirectories**:
  - [render](./render/README.md): Vulkan DMA-BUF allocation, glyph texture atlas rasterization, and `wgpu` rendering pipeline.
  - [term](./term/README.md): `vte`-backed terminal state machine, primary/alternate screen `Grid`, and hyperlink/text extraction.

## Invariants
- `[split.rs:MAX_PANES_PER_TAB]`: Each notebook tab page may contain at most `4` `TerminalView` panes; `split_terminal_with_widget` and `merge_tabs` reject operations where `current_panes + new_panes > MAX_PANES_PER_TAB` (and `merge_tabs` rejects self-merges or empty pages).
- `[config.rs:ConfigManager::set_window_opacity]` & `[config.rs:ConfigManager::set_color_saturation]`: Window opacity is clamped to `0.20..=1.0`, and color saturation boost is clamped to `1.0..=2.0`. `[main.rs:win_scroll]` & `[settings_dialog.rs:open_settings_dialog]` enforce mutual exclusion: when level `<= 1.0`, opacity is set and saturation resets to `1.0`; when level `> 1.0` with `experimental_supersaturation` enabled, opacity is pinned to `1.0` and saturation scales up to `2.0`.
- `[config.rs:ConfigManager::save]` & `[config.rs:ConfigManager::load_or_default]`: Enforces `0o700` permissions on the config directory and `0o600` atomic temp-file replacement on `config.toml`; malformed existing `config.toml` files are backed up with `0o600` permissions and `corrupt_backup_pending` blocks automatic tab-state saves until an explicit user configuration save succeeds.
- `[pty.rs:Pty::spawn_inner]` & `[pty.rs:Pty::terminate]`: Uses `libc::openpty` with `FD_CLOEXEC` on the master FD, `IUTF8` on the slave `termios`, scrubs inherited `WHATTY_SSH_ASKPASS_*`/`SSH_ASKPASS*` environment variables, and runs `setsid()` + `ioctl(0, TIOCSCTTY, 0)` in `pre_exec`; `Pty::terminate` (and `Drop`) checks non-blocking child exit first (`try_wait_exit_code`) before sending `SIGHUP` and escalating to `SIGKILL` to `-pid`.
- `[ssh.rs:build_remote_bootstrap_script]`, `[ssh.rs:build_ssh_invocation]`, & `[ssh.rs:AskpassBroker]`: Remote bootstrap emits a single-line POSIX `sh -c '...'` script free of `'`, `\`, and `\n` for `tmux`/`screen`; `ssh` invocations validate `host`/`user`, place `--` before the destination, never write credentials into `config.toml`, process args, or PTY stdin, and authorize UNIX socket askpass requests via `SO_PEERCRED` (`uid == getuid()`) plus single-use 128-bit nonces (`[ssh.rs:AskpassAttempt]`).
- `[widget.rs:TerminalView::with_shell_and_working_dir]` & `[widget.rs:TerminalView::with_ssh_profile]`: Polls the PTY master FD on the GTK main loop via `g_unix_fd_add_full` (`unix_fd_add_local`), reading at most `64 * 1024` bytes (`64 KiB`) per wakeup in `8192`-byte chunks; non-zero `SavedSsh` exits display an in-pane banner and wait for `Return`/`KP_Enter` before emitting `"child-exited"`, and `current_working_dir` returns `pre_ssh_local_dir` so `SavedSsh` tabs restore as disconnected local shells on restart.
- `[widget.rs:imp::TerminalView::snapshot]` & `[widget.rs:TerminalView::with_shell_and_working_dir]`: Maintains two ping-pong `DmabufFrame` buffers (`[Option<DmabufFrame>; 2]`), blocks on `device.poll(wgpu::PollType::wait_indefinitely())` before presenting to GTK, and drops both DMA-BUF frames on unmap (background tabs).
- `[widget.rs:imp::TerminalView::dispose]` & `[widget.rs:TerminalView::terminate]`: Takes `Option<TerminalViewInner>` via `.take()`, making teardown idempotent.
- `[theme_marketplace.rs:download_and_extract_theme_with_progress]`: Resolves themes in order: built-in presets (`popular_presets()`), local cache (`<cache_dir>/WhattyTheShell!/themes/<safe_id>_<version>.json`), then VSIX download (`Microsoft.VisualStudio.Services.VSIXPackage`).
- `[main.rs:format_dir_path]`: Replaces `$HOME` prefix with `~` and keeps displayed tab path strings bounded to `MAX_CHARS = 30`.

## Side Effects
- `[config.rs:ConfigManager::load_or_default]` & `[config.rs:ConfigManager::save]`: Creates and writes `$XDG_CONFIG_HOME/WhattyTheShell!/config.toml` (`0o600` in a `0o700` directory) on initialization (when missing) and on configuration setter calls.
- `[ssh.rs:SecretServiceClient]` & `[ssh.rs:AskpassBroker]`: Connects to the user session D-Bus (`org.freedesktop.secrets`) to store, look up, or delete SSH secrets encrypted in the desktop keyring, and binds a private `0o600` UNIX stream socket under `$XDG_RUNTIME_DIR/whatty/` (`0o700`) for `SSH_ASKPASS` requests.
- `[fonts.rs:shared_font_db]` & `[fonts.rs:get_cached_face_data]`: Loads OS system fonts once into a global `OnceLock<fontdb::Database>` and caches font face bytes in `FONT_DATA_CACHE`.
- `[pty.rs:Pty::spawn_inner]` & `[pty.rs:Pty::current_working_dir]`: Allocates kernel PTY devices (`openpty`), spawns child shell processes, sends `TIOCSWINSZ` (`SIGWINCH`) on resize, and reads `/proc/<fg_pgrp>/cwd` or `/proc/<pid>/cwd`.
- `[theme_manager.rs:ThemeManager::apply_to_window]` & `[theme_manager.rs:ThemeManager::set_theme]`: Registers a `gtk4::CssProvider` at `STYLE_PROVIDER_PRIORITY_APPLICATION` on the display, and (`set_theme`) performs blocking HTTP GET requests to GitHub raw URLs.
- `[theme_marketplace.rs:search_themes]` & `[theme_marketplace.rs:download_and_extract_theme_with_progress]`: Performs blocking HTTP POST/GET requests to `https://marketplace.visualstudio.com/_apis/public/gallery/extensionquery` and VSIX endpoints, caching extracted JSON color maps under `$XDG_CACHE_HOME/WhattyTheShell!/themes/`.
- `[settings_dialog.rs:update_user_desktop_icon]`: Rewrites `Icon=` in `$XDG_DATA_HOME/applications/io.github.whattytheshell.desktop` and spawns `update-desktop-database`.
- `[widget.rs:TerminalView::open_url]`: Launches `gtk4::UriLauncher`, `gio::AppInfo::launch_default_for_uri`, `code --goto`, `xdg-open`, or `gtk4::FileLauncher` when activating URLs or file paths.
- `[main.rs:main]`, `[main.rs:close_tab_page]`, & `[widget.rs:TerminalView::terminate]`: Blocks on `pollster::block_on` for `wgpu` adapter/device creation, installs GTK display CSS providers and `glib::timeout_add_local` (200 ms CWD polling per tab and 35 ms autoscroll timer), writes to GTK clipboards, and invokes `libc::malloc_trim(0)` when tabs or terminal views are destroyed.
