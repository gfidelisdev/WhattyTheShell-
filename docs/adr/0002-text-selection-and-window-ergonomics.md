# Text Selection and Window Ergonomics Strategy

We need interactive text selection, clipboard integration, hyperlink navigation, and window transparency controls in WhattyTheShell. We decided to implement Freedesktop-compliant primary selection alongside the standard clipboard, double/triple click selection modes, GPU-based translucent selection highlighting, modifier-click hyperlink launching, and window opacity control with an experimental color supersaturation overdrive mode beyond 100%. This ensures parity with standard Linux terminal emulators while preserving GPU rendering performance.
